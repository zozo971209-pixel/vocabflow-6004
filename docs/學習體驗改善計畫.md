# 學習體驗改善計畫

使用者已同意全部執行，可分批。所有意思保留顯示；只將有明確依據的主要意思加粗，不收合其他意思。

## 批次與驗收

1. 基本詞義與主要意思：建立依單字 ID、詞性及精確詞義的來源記錄，修正錯配縮寫；測驗與搜尋共用修正後資料。第一批先處理 a/an、am/a.m.、pm/p.m.、potential；其餘詞條仍待逐批檢查。
2. 每日複習與錯題：依學習時間和作答安排複習、測驗後只重練錯題、次日可找回，與手動熟悉度分開儲存。驗收舊紀錄相容、日期推進、錯題重練範圍。
3. 判分與備份：修正過寬中文前綴判分、顯示拼字／詞形／詞義差異；匯入預覽、合併／取代與復原。驗收一個正確意思可通過、錯誤否定不可通過、匯入失敗不改資料。
4. 內容：逐詞義完善雙語例句、自然搭配、所有延伸英文的中文與同義詞差異。驗收詞義對應、粗體位置、原文完整性及來源；不能用只有來源或沒有截斷代替自然度核驗。
5. 手機：延伸字體與例句跟隨設定、觸控尺寸、單欄與閱讀位置。驗收窄螢幕、長字與大字體，包含實際畫面。

## 主要意思判定

- 官方詞性確定詞條身份與詞性範圍；官方分級不等於詞義頻率。
- 學習字典的一般現代用法、詞義級別與用法標記支持編輯選擇。不得只取字典第一條。
- 不同詞性分別選定，可有多個主要意思。專業、古老或少見義保留顯示，但不得因位置靠前自動標粗。
- 有疑義時不標粗。尚未建立證據的詞條也不使用自動第一義備援。
- 每筆選擇記錄於 app/meaningEditorial.ts，附來源與理由。標粗代表本站學習優先建議；沒有歷屆試題詞義統計就不聲稱常考。
- 保留 public/vocab.json 原始資料；修正透過共用資料載入層套用，避免破壞單字 ID、學習進度和來源。
