# 詞序 VocabFlow

以大考中心現行高中英文參考詞彙表為基礎的每日學習網站，共收錄 6,004 個官方詞條。

## 網站

https://zozo971209-pixel.github.io/vocabflow-6004/

## 功能

- 前 120 天每天固定 50 詞，第 121 天為最後 4 詞
- 可用日期選擇器或「今天」直接跳到對應學習日
- 每天平均混合第 1–6 級與不同字母開頭
- 英文朗讀可切換正常（0.52）／慢速（0.26）／超慢速（0.13），並在朗讀前移除斜線、括號、詞性與音標等符號
- 已熟悉、待複習與不熟標記
- 中文解釋依詞性分組，法律、醫學、化學、電腦等專業義另列；不以粗體推測字義主次
- 6,004 個詞條皆有依個別詞義整理的完整英中例句；只將英文目標詞及中文對應詞加粗
- 當日 50 詞或自訂天數範圍測驗，可選四選一或填充題；兩種題型都支援中英雙向與隨機出題，英填中只需回答一個正確中文意思
- 可選每題計時並自訂 5–300 秒；時間到顯示答案，不會自動跳題
- 測驗可複選已熟悉、待複習與不熟，並與所選天數範圍交集出題
- 測驗成績與錯題保存在瀏覽器，並可隨進度備份轉移
- 可搜尋全部、目前學習日或任意 Day 範圍，並依級別、狀態與收藏篩選；目前條件會以可移除標籤顯示
- 可直接測驗目前篩選結果，或以專注模式逐詞顯示答案並標記熟悉度
- 可隱藏中文後逐詞揭曉與收藏單字；首頁可一鍵篩選全部收藏，或沿用上次偏好直接開始測驗
- 學習進度保存在使用者自己的瀏覽器
- 進度可匯出成備份檔，並在新手機或其他裝置匯入恢復
- 可安裝為 PWA；首次完整載入後可離線學習、測驗與寫筆記
- 亮色／深色模式與三段字體大小
- 每張卡片先顯示例句，再按需展開搭配與相關詞、個人筆記；空白分類不佔版面，個人筆記與收藏也包含在備份中
- 「搭配詞／句型」只顯示通過結構篩選的內容，完整例句不會誤列為句型；未提供差異說明的自動同義詞不會直接顯示
- 手機與桌面響應式介面

## 本機執行

```bash
npm install
npm run dev
```

## 資料說明

英文詞彙、官方詞性與六級分級來自大學入學考試中心《高中英文參考詞彙表（111學年度起適用）》。中文釋義與音標由 ECDICT 資料補充，並非大考中心官方中文翻譯。

延伸學習內容主要取自 Open English WordNet 2025（CC BY 4.0）及專案內的核對紀錄，再依本站詞彙資料整理。介面會優先顯示 canonical 雙語例句，並保守隱藏機械句型、低價值自動詞族、泛用占位用法及缺乏差異說明的自動同義詞。

延伸學習資料由 `public/enrichment.json` 載入。匯出流程只接受欄位完整、具可追溯來源，且 `verification_status` 為 `human_verified` 的資料；未完成核對的候選內容不會作為正式資料顯示。

AI／詞典自動整理資料由 `public/enrichment-ai.json` 載入。可使用 `node scripts/build-ai-enrichment.mjs <Open English WordNet JSON 目錄>` 重新產生英文延伸資料，再以 `python scripts/build-enrichment-glosses.py <ECDICT CSV>` 補上詞族、搭配詞與同義詞的繁體中文提示。後者會優先採用 ECDICT，只有查不到的詞組才交由本機 Ollama 翻譯；`python scripts/audit-enrichment-glosses.py` 可用多語嵌入模型篩查明顯錯配。

搭配詞發布前可執行 `python scripts/clean-collocations.py`：固定格式的機械備援內容與從長句截出的片段會直接移除，只保留本身就是完整 WordNet 範例的自然搭配、完整短句及少數明確維護的基本用法。

主要雙語例句由 `public/canonical-examples.json` 載入；`public/bilingual-examples.json` 保留作相容備援。資料稽核會檢查詞條覆蓋、目標詞形、繁體中文、重複及標示位置，介面不顯示舊的草稿提示文案。
